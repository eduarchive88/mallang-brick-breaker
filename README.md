# 말랑 벽돌깨기 🍬

말랑말랑 젤리 친구들을 깨는 귀여운 벽돌깨기 게임이에요.

▶ 플레이: https://eduarchive88.github.io/mallang-brick-breaker/

## 조작법
- 마우스 / 터치로 패들 움직이기, 또는 ← → 키
- 클릭 · 탭 · 스페이스로 공 발사
- 떨어지는 사탕을 받으면 선물! (넓은 패들, 공 셋, 하트+1, 느릿느릿)

## 특징
- 5개 스테이지 (모두 깨면 더 빨라져서 다시 시작)
- 두 번 맞아야 깨지는 단단한 하얀 젤리
- 연속으로 깨면 콤보 점수
- 최고 점수 저장
- 설치 없이 index.html 하나로 동작
